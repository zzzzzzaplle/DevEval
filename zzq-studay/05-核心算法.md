# 核心算法

## Pass@k 算法

### 算法原理

Pass@k 是评估代码生成功能正确性的指标，计算在 k 个生成样本中至少有一个通过所有测试的概率。

### 数学定义

对于每个任务：
- **n**: 为该任务生成的代码样本总数
- **c**: 通过所有测试的样本数量
- **k**: 考虑的前 k 个样本

**Pass@k 计算公式**:

```
Pass@k = 1 - C(n-c, k) / C(n, k)
```

**展开形式**:

```python
def compute_pass_at_k(n, c, k):
    """
    n: 每个任务的样本总数
    c: 通过测试的样本数
    k: 前k个样本
    """
    if n - c < k:
        return 1  # 如果失败样本数 < k，必有一个通过
    else:
        return 1.0 - np.prod(1.0 - k / np.arange(n-c+1, n+1))
```

```python
                    return 'Error'
                else:
                    break
        
        process.terminate()
    
    return 'Pass'
```

```python
def SetUp_evaluation(args, data, completion):
    """准备评估环境"""
    completion_path = Path(data['completion_path'])
    completion_path = os.path.join(args.source_code_root, completion_path)
    
    # 备份原文件
    completion_tmp_path = completion_path.replace('.py', 'tmp_.py')
    run(['cp', completion_path, completion_tmp_path])
    
    # 替换函数体
    sos, eos = data['body_position'][0]-1, data['body_position'][1]
    with open(completion_path, 'r') as f:
        file_lines = f.readlines()
    
    # 插入生成的代码
    file_lines = file_lines[:sos] + ['\n', completion, '\n'] + file_lines[eos:]
    
    with open(completion_path, 'w') as f:
        f.write(''.join(file_lines))

def TearDown_evaluation(args, data):
    """清理评估环境"""
    completion_path = Path(data['completion_path'])
    completion_tmp_path = completion_path.replace('.py', 'tmp_.py')
    
    # 恢复原文件
    run(['mv', completion_tmp_path, completion_path])
```

**流程**:
1. 备份原文件

```python
def report_results(args, benchmark_data):
    """统计评估结果"""
    # 收集通过的样本
    passed_completion = {}
    with open(args.log_file, 'r') as f:
        for line in f:
            js = json.loads(line)
            if js['Result'] == 'Pass':
                namespace = js['namespace']
                completion = js['completion']
                if namespace not in passed_completion:
                    passed_completion[namespace] = set()
                passed_completion[namespace].add(completion)
    
    # 统计每个任务通过的数量
    results = {}
    with open(args.output_file, 'r') as f:
        for line in f:
            js = json.loads(line)
            namespace = js['namespace']
            completion = js['completion']
            
            if namespace not in results:
                results[namespace] = 0
            
            if completion in passed_completion.get(namespace, set()):
                results[namespace] += 1
    
    # 计算 Pass@k
    k_list = [int(k) for k in args.k.split(',')]
    for k in k_list:
        pass_at_k = np.mean([
            compute_pass_at_k(args.n, pass_num, k) 
            for namespace, pass_num in results.items()
        ])
        print(f'pass_at_{k}: {pass_at_k*100}%')
```

## Recall@k 算法

### 算法原理

Recall@k 评估模型生成的代码是否正确识别和使用依赖关系。

### 数学定义

**Recall 计算**:

```
Recall = |预测依赖 ∩ 真实依赖| / |真实依赖|
```

**Recall@k**: 取前 k 个样本中的最高召回率

### 算法实现

#### 1. 依赖关系分类

```python
def predict_relationship(candidate_name: str, attributes: dict):
    """
    预测依赖关系类型
    
    参数:
        candidate_name: 候选依赖名称
        attributes: 当前函数属性
    
    返回:
        'intra_class': 类内依赖
        'intra_file': 文件内依赖
        'cross_file': 跨文件依赖
    """
    if attributes['type'] == 'function':
        # 函数: 判断是否同文件
        file_path = '.'.join(attributes['namespace'].split('.')[:-1])
        if candidate_name.startswith(file_path):
            return 'intra_file'
        else:
            return 'cross_file'
    
    elif attributes['type'] == 'method':
        # 方法: 判断类内/文件内/跨文件
        class_path = '.'.join(attributes['namespace'].split('.')[:-1])
        if candidate_name.startswith(class_path):
            return 'intra_class'
        
        file_path = '.'.join(attributes['namespace'].split('.')[:-2])
        if candidate_name.startswith(file_path):
            return 'intra_file'
        
        return 'cross_file'
```

#### 2. 召回率计算

```python
def compute_recall(generated_dependency, reference_dependency):
    """
    计算依赖召回率
    
    参数:
        generated_dependency: 生成的依赖字典
        reference_dependency: 真实的依赖字典
    
    返回:
        recall: 召回率 [0, 1]
    """
    # 合并所有依赖
    reference = []
    for _type, _list in reference_dependency.items():
        reference.extend(_list)
    
    if generated_dependency is None:
        return 0
    
    prediction = []
    for _type, _list in generated_dependency.items():
        prediction.extend(_list)
    
    # 计算召回率
    reference = set(reference)
    prediction = set(prediction)
    recall = len(reference.intersection(prediction)) / len(reference)
    
    return recall
```

```python
def extract_dependency(args, data):
    """从解析结果中提取依赖"""
    generated_dependency = {
        'intra_class': [],
        'intra_file': [],
        'cross_file': []
    }
    
    dependency_path = os.path.join(
        args.dependency_tmp_dir,
        data['completion_path'].replace('.py', '.json')
    )
    
    if not os.path.exists(dependency_path):
        return generated_dependency
    
    with open(dependency_path, 'r') as f:
        dependency_data = json.load(f)
    
    if data['namespace'] not in dependency_data:
        return generated_dependency
    
    attributes = dependency_data[data['namespace']]
    
    # 提取各类依赖
    for _item in attributes['in_class']:
        generated_dependency['intra_class'].append(_item['name'])
    
    for _item in attributes['in_file']:
        generated_dependency['intra_file'].append(_item['name'])
    
    for _item in attributes['in_object']:
        generated_dependency['cross_file'].append(_item['name'])
    
    return generated_dependency
```

```python
def report_results(args, k_list, output_data, benchmark_data):
    """计算并报告 Recall@k"""
    results = {}
    
    for namespace, outputs in output_data.items():
        for output in outputs:
            completion = output['completion']
            if namespace in parse_results and namespace in benchmark_data:
                generated_dependency = parse_results[namespace][completion]
                reference_dependency = benchmark_data[namespace]['dependency']
                recall = compute_recall(generated_dependency, reference_dependency)
                
                if namespace not in results:
                    results[namespace] = []
                results[namespace].append(recall)
    
    # 计算 Recall@k
    for k in k_list:
        recall = 0
        for namespace, recall_list in results.items():
            recall += max(recall_list[:k])  # 取前k个中的最大值
        
        recall /= len(results)  # 平均召回率
        print(f"Recall@{k}: {recall*100}%\n")
```

## 算法特点

### Pass@k 特点

**优点**:
- 直接评估功能正确性
- 结果易于理解
- 广泛接受的评估标准

**缺点**:
- 依赖测试用例质量
- 执行时间长
- 需要完整运行环境

### Recall@k 特点

**优点**:
- 评估对上下文的理解
- 不依赖测试用例
- 快速评估

**缺点**:
- 仅评估依赖识别
- 静态分析可能不完整
- 不评估代码正确性

## 指标解读

### Pass@k 结果示例

```
pass_at_1: 45.2%
pass_at_3: 62.8%
pass_at_5: 71.3%
pass_at_10: 82.5%
```

**解读**:
- Pass@1 表示单次生成的成功率
- k 越大，通过率越高
- Pass@k 增长率反映模型稳定性

### Recall@k 结果示例

```
Recall@1: 38.5%
Recall@3: 52.3%
Recall@5: 61.7%
```

**解读**:
- Recall@1 表示单次生成的依赖识别率
- 高召回率意味着更好的上下文理解
- 独立样本的召回率通常较低
