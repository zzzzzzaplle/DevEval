## 🎯 学习目标

- 理解代码生成基准测试的设计理念
- 掌握 DevEval 的数据组织和评估方法
- 学习 Pass@k 和 Recall@k 评估指标
- 了解仓库级代码生成的实验设置

## 📊 项目亮点

- **真实仓库数据**：来自 115 个真实世界代码仓库
- **多维度对齐**：代码和依赖分布与实际仓库一致
- **全面评估**：功能正确性和依赖召回率双重评估
- **1825 个测试样本**：覆盖 10 个编程主题
