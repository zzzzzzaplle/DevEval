## 核心文件说明

### 1. 评估脚本

#### pass_k.py
**功能**: 计算 Pass@k 指标
- 评估生成代码的功能正确性
- 运行测试用例并统计通过率
- 支持多个 k 值计算 (k=1,3,5,10)
- 关键函数：
  - `execution_tests()`: 执行测试用例
  - `compute_pass_at_k()`: 计算 Pass@k 值
  - `SetUp_evaluation()`: 准备评估环境
  - `TearDown_evaluation()`: 清理评估环境

#### recall_k.py
**功能**: 计算 Recall@k 指标
- 评估依赖关系的召回率
- 分析类内、文件内、跨文件依赖
- 关键函数：
  - `parse_dependency()`: 解析依赖关系
  - `compute_recall()`: 计算召回率
  - `extract_dependency()`: 提取依赖信息

### 2. 工具模块

#### utils.py
**功能**: 通用工具函数
- 依赖关系预测 (`predict_relationship()`)
- AST 遍历 (`traverse_ast()`)
- 导入语句搜索 (`search_import()`)
- 代码缩进调整 (`adjust_indent()`)

#### check_source_code.py
**功能**: 检查源代码完整性
- 检查是否有临时文件残留
- 恢复原始代码文件
- 确保评估环境干净

### 3. 数据文件

#### data.jsonl
**格式**: 每行一个 JSON 对象
**内容**: 测试样本的元数据

示例：

```json
  "namespace": "benedict.utils.type_util.is_json_serializable",
  "type": "function",

  "signature_position": [53, 53],
  "body_position": [54, 55],
  "dependency": {
    "intra_class": [],
    "intra_file": [],
    "cross_file": []
  },
  "requirement": {
    "Functionality": "Check if the input value is JSON serializable...",
    "Arguments": ":param val: Any. The input value..."
  },
  "tests": ["tests/utils/test_type_util.py::type_util_test_case::test_is_json_serializable"],
  "indent": 4

```

### 4. 实验目录

#### Experiments/model_prediction/
**内容**: 模型生成的代码补全结果
- `without_context/`: 无上下文生成的结果
- `local_completion/`: 本地文件上下文生成的结果
- `local_infilling/`: 本地文件填充生成的结果

**支持的模型**:
- GPT-4-1106-Preview
- GPT-3.5-Turbo-1106
- CodeLLaMA (7B/13B)
- DeepSeek (7B/33B)
- StarCoder2-15B

#### Experiments/prompt/
**内容**: 提示词模板
- `LM_prompt_elements.jsonl`: 语言模型的提示元素
- 各个设置下的具体提示词

### 5. 解析器目录

#### parser/
**内容**: 依赖解析工具
- `get_func_call.py`: 获取函数调用关系
- `add_func_call.py`: 添加函数调用信息
- `pyan_zyf_v2/`: Python 依赖分析器
