# 项目介绍

## 项目概述

**DevEval** 是一个代码生成基准测试数据集，通过严格的流程收集而成。它包含了 **1,825 个测试样本**，这些样本收集自 **115 个真实的代码仓库**，覆盖了 **10 个编程主题**。

## 核心特点

### 1. 真实仓库对齐

与现有的基准测试相比，DevEval 在多个维度上与真实世界仓库对齐：
- **代码分布**：代码结构、复杂度与真实项目一致
- **依赖分布**：依赖关系反映了实际开发场景
- **真实场景**：来自开源项目的实际需求

### 2. 多样化覆盖

- **10 个编程主题**：
  - 文本处理 (Text Processing)
  - 数据处理 (Data Processing)
  - 网络编程 (Network Programming)
  - 科学计算 (Scientific Computing)
  - Web 开发 (Web Development)
  - 工具库 (Utilities)
  - 其他主题

- **115 个真实仓库**：涵盖不同规模和领域的项目

### 3. 双重评估机制

DevEval 提供了两种互补的评估指标：

#### Pass@k (功能正确性)
- 评估生成的代码是否通过所有测试用例
- 基于 k 个生成样本计算通过率
- 反映代码的功能正确性

#### Recall@k (依赖召回率)
- 评估生成的代码是否正确识别和使用依赖
- 分析类内依赖、文件内依赖、跨文件依赖
- 反映对项目上下文的理解能力

## 与其他基准测试的对比

| 特性 | DevEval | HumanEval | MBPP |
|------|---------|-----------|------|
| 数据来源 | 真实仓库 | 手工编写 | 手工编写 |
| 样本数量 | 1,825 | 164 | 974 |
| 依赖关系 | 有 | 无 | 无 |
| 仓库级上下文 | 支持 | 不支持 | 不支持 |
| 测试用例 | 真实测试 | 手工编写 | 手工编写 |

## 研究意义

### 1. 更真实的评估环境
- 反映实际开发中的代码生成任务
- 考虑项目依赖和上下文
- 提供更可靠的模型性能评估

### 2. 推动代码生成研究
- 为仓库级代码生成提供标准基准
- 促进上下文感知代码生成研究
- 支持依赖分析和代码理解研究

### 3. 实用价值
- 帮助开发者了解 LLM 代码生成能力
- 为代码生成工具提供评估标准
- 推动智能编程助手的发展
